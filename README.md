# Automated Driver Grading System
The Automated Driver Grading System transforms any smartphone into an objective driving assistant. By evaluating behaviors like speed, focus, smoothness, and following distance, it provides beginners with consistent feedback to build safer driving habits. Users can also view historical data, obtain tailored trend-based suggestions, share their progress, receive live voice feedback, and switch driving modes.
